# 卖车话术教练 · 闲鱼版（v3）

给「在闲鱼帮老板卖二手电动车」的学生用的对话训练 + 段位榜工具。单文件 HTML，离线可用。

## 五个模块
- **查话术**：粘贴买家原话 → 匹配场景 → 推荐回复 + 原理 + 下一句 + 禁忌
- **训练场**：出题 → 自己写 → 评分点评（《认知天性》检索练习 + 间隔重复）
- **榜单**：账号注册/登录 + 六级段位 + 积分榜；**只有管理员能改分**
- **话术库**：45 场景 / 29 原理卡 / 七步 SOP / 五条红线
- **我的**：定价计算器、闲鱼标题文案生成器、练习数据、云端设置

## 账号系统
- 只用 **名字 + 密码** 注册，不要手机号（手机号/学号会被校验拦下）
- 注册即上榜，初始 0 分 · 一级见习
- 密码用 PBKDF2-SHA256（12 万次迭代 + 每人独立盐）后再存储，前端不存明文
- 管理员内置：**用户名 `老板`，密码 `che1688`**（首次登录后请改密码）

## 两种运行模式
| 模式 | 说明 |
|---|---|
| 本机模式（默认） | 账号存本地，只有这台手机能注册/登录，不需要任何注册和配置 |
| 云端模式 | 接 Supabase 免费版，学生跨手机注册、你改分实时生效 |

开云端：`我的 → 云端同步 → 复制建表 SQL` → Supabase SQL Editor 执行 → 把 Project URL 和 anon key 填回来。
SQL 里已包含管理员行、RLS、以及 register/login/admin 全套 RPC（管理操作在数据库端校验管理员身份）。

## 段位
一级见习 0 / 二级上路 100 / 三级教头 300 / 四级掌柜 600 / 五级合伙人 1000 / 六级宗师 2000
（老板固定三级，不随积分变动）
