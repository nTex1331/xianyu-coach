# 卖车话术教练 · 闲鱼版（v4）

给「在闲鱼帮老板卖二手电动车」的学生用的对话训练 + 业绩记账工具。单文件 HTML，离线可用。

## 五个模块
- **查话术**：粘贴买家原话 → 匹配场景 → 推荐回复（含「转老板型」）+ 原理 + 下一句 + 禁忌
- **训练场**：出题 → 自己写 → 评分点评（《认知天性》检索练习 + 间隔重复）
- **业绩**：今日销售额大字卡 + 记一笔/改一笔 + 最近 7 天 + 本月合计/日均/最高
- **话术库**：46 场景 / 29 原理卡 / 七步 SOP / 六条红线
- **我的**：定价计算器、闲鱼标题文案生成器、练习数据

## 一条硬规矩
**上牌、过户、发票、售后年限、能不能开票——一律转老板**，学生不自己拍板。
页面里 6 个场景带「转老板型」话术，另有独立场景「答不上来的问题（一律转老板）」，红线里也写死了。

## 数据
练习记录与销售额都存在浏览器 localStorage（只在本机）。换手机前用「我的 → 导出备份」。
