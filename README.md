# 卖车话术教练 · 闲鱼版

给「在闲鱼帮老板卖二手电动车」的学生用的对话训练工具。单文件 HTML，离线可用。

## 四个功能
- 查话术：粘贴买家原话 → 匹配场景 → 推荐回复 + 原理拆解 + 下一句 + 禁忌
- 训练场：出题 → 自己写回复 → 评分点评（《认知天性》检索练习 + 间隔重复）
- 话术库：45 个场景 / 29 条原理卡 / 七步 SOP / 五条红线
- 我的：定价计算器、闲鱼标题文案生成器、练习数据

## 理论来源
《关键对话》安全感与 STATE｜《影响力》六武器｜《先发影响力》注意力前置｜
《认知天性》检索练习｜《影响力大师》关键行为与六源｜《毛选》抓主要矛盾、集中优势兵力。

## 开发
```
python build.py          # 合并 template.html + data_*.js → index.html
node test_logic.js       # 数据/匹配/评分逻辑测试
cdpvenv/Scripts/python.exe e2e_test.py   # 端到端（需 http.server 8766 + Edge CDP 9223）
```
