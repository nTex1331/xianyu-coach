# 卖车话术教练 · 闲鱼版

给「在闲鱼帮老板卖二手电动车」的学生用的对话训练 + 积分段位工具。单文件 HTML，离线可用。

## 五个功能
- 查话术：粘贴买家原话 → 匹配场景 → 推荐回复 + 原理拆解 + 下一句 + 禁忌
- 训练场：出题 → 自己写回复 → 评分点评（《认知天性》检索练习 + 间隔重复）
- 榜单：六级段位 + 积分排行榜，老板口令解锁后可加人/改分/改等级；学生通过分享链接只读查看
- 话术库：45 个场景 / 29 条原理卡 / 七步 SOP / 五条红线
- 我的：定价计算器、闲鱼标题文案生成器、练习数据

## 榜单机制
- 成员只用真名或微信名登记，手机号会被校验拦截
- 默认口令 `8888`，解锁后可修改；口令存在本机
- 「生成榜单链接」把当前榜单编码进 URL 的 `#b=` 里，学生打开即只读（改不了）
- 「复制战报文案」直接发微信群
- 等级：一级见习 0 / 二级上路 100 / 三级教头 300 / 四级掌柜 600 / 五级合伙人 1000 / 六级宗师 2000

## 理论来源
《关键对话》安全感与 STATE｜《影响力》六武器｜《先发影响力》注意力前置｜
《认知天性》检索练习｜《影响力大师》关键行为与六源｜《毛选》抓主要矛盾、集中优势兵力。
